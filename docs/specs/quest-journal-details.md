# Owned quest journal details

- Quest log snapshots and updates include authoritative story text, current money/fixed/choice rewards, and pushability for every owned quest.
- Fresh login and reconnect must not require a quest-giver interaction to recover these fields.
- Pushability excludes non-shareable and failed quests; the client additionally requires current group membership to enable Share.
- Fields are required protocol data. No legacy/default-value compatibility path.
